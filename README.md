# CSV Sentiment Tagger

An automated sentiment analysis and text tagging script built with Python. Designed to process CSV datasets, evaluate text polarity or sentiment, and tag rows for data intelligence and customer feedback pipelines.

## Features
* **CSV Processing:** Automatically reads and parses large tabular datasets.
* **Sentiment Analysis:** Evaluates textual data to categorize sentiment.
* **Automated Tagging:** Appends classification tags back into structured outputs.
* **Lightweight & Efficient:** Built with clean Python code for fast data processing.

## Tech Stack
* Python 3.x
* CSV processing & data handling libraries
